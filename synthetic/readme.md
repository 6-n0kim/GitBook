# 합성 데이터 개요

### 합성 데이터란?

원본의 값을 가리거나 바꾼 것이 아니라, 원본의 통계적 특성(분포, 컬럼 간 관계)을 학습한 모델로 새로 만들어낸 데이터입니다.

#### 합성 방식 비교

합성에는 여러 방식이 쓰이는데, 각각 잘 맞는 데이터와 상황이 다릅니다.

| 방식                      | 특징                                    | 한계                                                            |
| ----------------------- | ------------------------------------- | ------------------------------------------------------------- |
| **GMM** (가우시안 혼합 모델)    | 데이터를 여러 개의 정규분포가 섞인 형태로 보고 학습         | 수치형 전용. 범주형은 억지로 숫자 변환해야 하고, 생성값이 소수점으로 나와 원래 카테고리로 되돌리기 어려움  |
| **GAN** (생성적 적대 신경망)    | 생성자와 판별자를 경쟁시켜 학습. 복잡한 비선형 관계까지 재현 가능 | 대량의 데이터와 GPU·하이퍼파라미터 튜닝이 필요. 학습이 불안정하고, 왜 그런 값이 나왔는지 설명하기 어려움 |
| **synthpop** (순차적 CART) | 컬럼을 하나씩 순서대로, 앞선 컬럼을 조건으로 삼아 합성       | 예측 변수로 지정한 관계만 반영됨. 나무가 너무 세밀해지면 원본을 그대로 베낄 수 있음              |

#### 이 실습에서 synthpop을 선택한 이유

범주형과 수치형을 함께 다룰 수 있고, 수천\~수만 건 규모의 정형 데이터에 안정적으로 작동합니다. 각 컬럼이 어떤 조건으로 합성됐는지 Tree 구조로 확인할 수 있어 **검증과 설명이 가능합니다**.
