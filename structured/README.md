# 정형 데이터 비식별 실습

CSV, Excel 등 구조화된 데이터에서 개인정보를 비식별화하는 실습입니다.

**실습 내용:**
- 데이터 정제 - Data Cleansing
- 개인정보 비식별처리 (가명처리 / 익명처리)
- 데이터 시각화 및 검증 ()
- 결과 검증 및 내보내기

**대상 데이터:**
- CSV 파일
- Excel 파일
- 데이터베이스 덤프 파일
- JSON 형식의 구조화된 데이터
